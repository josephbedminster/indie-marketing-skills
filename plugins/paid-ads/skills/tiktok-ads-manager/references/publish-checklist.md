# Checklist before Publish all / Submit

Check with `document.body.innerText` (search the labels) rather than by eye:

1. **Campaign**: objective App promotion > App install; Smart+ off (otherwise
   no manual targeting); "Use iOS 14 dedicated campaign" ON with the app
   selected ("eligible for iOS real-time reporting"); explicit name;
   campaign budget (TikTok can spend ~25 % more on some days for a 20 per day
   budget; weekly cap = 7 × daily budget).
2. **Ad group**: Optimization goal = **Install** (TikTok defaults to
   "Click"); Bid strategy = Maximum results; country; age range; iOS 14+;
   automatic placements; continuous delivery (spend starts as soon as it is
   approved).
3. **Ad**:
   - The brand's TikTok identity, "Only show as ads" checked.
   - "Selected recommended creatives": all three groups on "Don't add".
   - Manual creatives = exactly the intended videos ("Manually selected
     creatives (n)").
   - Text ≤ 100 characters, following the config's copy rules (banned words,
     punctuation, tone), one text per audience.
   - "This ad contains AI-generated content" checked **and** "Select creative
     assets" > Select all ("n creative assets selected" must equal the number
     of videos) when videos use AI-generated people or voices. Irreversible.
   - "Automatic enhancements": Turned on = CTA enhancement only; Turned off =
     Generate ad card, Translate and dub, Video quality, Music refresh.
   - Destination = Apple App Store.
4. **Recap to the user** in chat (table: targeting / videos / text / budget)
   plus the consequences (review, learning phase, spend starts). Wait for an
   explicit OK.
5. Click, wait 8-10 s, then re-read the ad list: "Not delivered" right after
   publishing = review in progress, normal. Note the new ids in the config.
